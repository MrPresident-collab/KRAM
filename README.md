# KRAM — Kore Remote Asset Management

Remote Asset Management for owners who need visibility and control over assets they cannot physically monitor.

## Stack
Next.js 16 · TypeScript · App Router · Tailwind CSS 4 · shadcn/ui · Lucide · Supabase · PostgreSQL · Vercel

## Localization
French is the default language. English and Portuguese are supported from day one.

- /fr
- /en
- /pt

## First build surface
Admin/Ops comes first. The application is organized around assets, clients, work orders, inspections, projects, providers, expenses, documents and audit history.

## Development
npm install
npm run dev
